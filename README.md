# generador_datos_mantenimiento
Notebook para generar tablas de una base de datos de mantenimiento industrial simulada

La idea de este proyecto es generar en forma artificial y simulada datos provenientes de un sistema de gestión
de mantenimiento ficticio y de una empresa ficticia, con el fin de contar con un dataset con suficiente complejidad
y poder ejecutar diversos análisis de datos con él.

La generación de realiza enteramente en un notebook jupyter sobre el cual se escriben las explicaciones pertinentes.
